## About Mailhub

Mailhub is a privacy-first email relay that helps keep your primary address out of third-party services. Create a random or custom relay address for each service, receive its messages in your regular inbox, and turn forwarding off when an address starts getting unwanted mail. You can also reply to forwarded messages without exposing your primary address.

## Explore the projects

- [backend](https://github.com/private-mailhub/backend) — NestJS API and SQS worker for managing relay addresses and processing incoming email.
- [frontend](https://github.com/private-mailhub/frontend) — React web app for creating and managing relay addresses.
- [cli](https://github.com/private-mailhub/cli) — Go command-line client for managing relay addresses and API keys with a compatible Mailhub server.

For setup, architecture, and project-specific details, start with the README in the repository you are interested in.
